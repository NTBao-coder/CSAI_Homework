## Mục tiêu Repository

- **Lý thuyết & Chứng minh:** Trình bày chi tiết các bước suy luận toán học, thiết kế thuật toán và trả lời câu hỏi lý thuyết cuối mỗi chương.
- **Thực thi (Implementation):** Cài đặt các thuật toán cốt lõi (Search, CSP, Logic, Planning, Probabilistic Reasoning, Machine Learning) bằng Python.
- **Tài liệu tham khảo:** Hệ thống hóa kiến thức nền tảng về Trí tuệ Nhân tạo một cách có cấu trúc.
